# متابعة غياب الطلاب — تطبيق قابل للتثبيت (PWA)

## الرفع على GitHub Pages
1. أنشئ مستودعًا جديدًا (مثل `student-absence`).
2. ارفع كل الملفات كما هي: `index.html` و`manifest.webmanifest` و`sw.js` ومجلد `icons`.
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. الرابط يصبح: `https://<اسم-المستخدم>.github.io/student-absence/`

## التثبيت
- **الكمبيوتر (Chrome / Edge):** افتح الرابط ← أيقونة التثبيت في شريط العنوان، أو زر «تثبيت التطبيق» داخل التطبيق.
- **أندرويد (Chrome):** القائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## البيانات
تُحفظ على كل جهاز وحده. لنقلها بين الجوال والكمبيوتر: الإعدادات ← تنزيل نسخة احتياطية ← استيرادها في الجهاز الآخر.

## التحديث
عند تعديل `index.html` غيّر قيمة `VERSION` في `sw.js` (مثل `absence-v2`) ليصل التحديث للأجهزة المثبّت عليها التطبيق.
